Run a Molibra node

Two dependencies, one command. The chain is small enough to verify from genesis on an ordinary machine, which is the point — nothing here asks you to trust this page.

1 · Get it

git clone https://github.com/BaronOdon/molibra.git
cd molibra
npm install

Node.js 20 or newer. Apache-2.0.

2 · Join the chain and mine

node src/cli.js node --port 8545 --datadir ./data \
  --peers … \
  --advertise http://YOUR-IP:8545 \
  --miner 0xYourAddress --mine
Your first start replays and re-verifies the whole chain before the RPC answers — minutes, not seconds, and it is not a hang. ⛔ Never restart a node mid-replay.

--advertise is the address other nodes should dial. Without it a node behind a wildcard bind cannot be followed back, so it only ever pulls.

3 · Check what you joined

curl http://127.0.0.1:8545/molibra          # your node's view
curl …/molibra   # the public node's view

Same height, same head hash a few blocks back: you are on the chain. Different: you are not, and the node will say so rather than pretend.

A wallet may warn that the network is unfamiliar. Chain 20226 is registered in ethereum-lists/chains; the warning is about what your wallet has seen before, not about whether the chain is real.

⛔ Two things to know before you mine

Mining is the only way to obtain MOLI here. There is no sale, no presale and no allocation. That is deliberate and it cuts both ways: nobody can buy a position, and nobody will hand you one either.
Crossing to Ethereum is ONE-WAY until Molibra block 118,000. Burning MOLI destroys it here and mints bMOLI there against a proof. From block 118,000, bMOLI sent to the keyless vault on /molibra/return comes back as MOLI at the sending address; before it, nothing brings it back. Cross only what you mean to leave.

A burn is claimable once its block has been anchored on Ethereum and a challenge window has passed — in practice about a day, not instantly.
