Como minerar · How to mine

Precisa de Node.js 20+ e do código da Molibra. Não precisa rodar um nó completo.
Needs Node.js 20+ and the Molibra source. No full node required.

git clone https://github.com/BaronOdon/molibra && cd molibra && npm install
node tools/pool-miner.mjs --address 0xSUA_CARTEIRA --worker rig1
  • PPLNS: cada bloco é dividido pelo trabalho dos últimos N shares (N = 2× a dificuldade do bloco). Each block is split over the last N shares of work.
  • Taxa de 1%, que paga o servidor e o gás dos pagamentos. 1% fee, covering the server and payout gas.
  • Pagamento automático a partir de 0,1 MOLI, depois que o bloco tem 130 confirmações. Automatic payout once a block is that deep (the chain can reorganise up to 128 blocks).
