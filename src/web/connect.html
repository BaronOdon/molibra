3 · Linking proof

Signs a one-time challenge with your wallet and produces a code to paste into the app. The signature proves you control the address. No key ever leaves your wallet, and the code moves no funds.

Mining

Real mining runs on a node you download and control, not in this tab. A browser can only contribute a token amount of work, and it will only ever do so after you press start — never in the background, never without telling you.
