How it works

bMOLI cannot be destroyed on Ethereum, so it is sent to a vault nobody can spend from: an address derived from a hash, with no private key behind it. Molibra reads the transfer out of an Ethereum receipt proof and releases the same amount of MOLI.

⛔ Send from a wallet whose key you hold. The MOLI is paid to the sender's address on Molibra. Sent from a contract (a swap router, a Safe), it lands at that contract's address, where nobody has a key. And the vault is final: bMOLI sent there never comes back out.
The bound: MOLI comes back only as MOLI that went out. A return larger than what is outstanding is refused by every node, however valid its proof.
